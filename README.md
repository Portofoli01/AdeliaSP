# Portofolio Adelia Setiawan Putri

Website statis (HTML + CSS + JS), tanpa proses build.

## Struktur
- `index.html` : halaman utama
- `slides.html` : versi slide (geser/swipe di Android, panah keyboard di laptop)
- `assets/img/` : foto
- `assets/CV-Adelia-Setiawan-Putri.pdf` : file CV yang diunduh lewat tombol "Unduh CV"

## Cara memasang di GitHub Pages
1. Buat repositori baru, unggah seluruh isi folder ini.
2. Buka Settings > Pages, pilih branch `main` dan folder `/ (root)`.
3. Situs aktif di `https://<username>.github.io/<nama-repo>/`.
